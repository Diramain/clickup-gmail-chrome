Qué podés hacer

  • Crear una tarea desde el mensaje que estás leyendo.
  • Vincular el correo con una tarea existente.
  • Conservar el enlace a Gmail y una copia HTML sanitizada.
  • Elegir archivos adjuntos compatibles para subirlos de forma explícita.

Campo Gmail Thread ID

Permite reconocer qué tarea ya está vinculada con un hilo sin depender del texto de la descripción.

  1. Creá en ClickUp un campo personalizado de tipo texto.
  2. Usá el mismo nombre en las listas donde vinculás correos.
  3. Guardá abajo el nombre exacto; por defecto se usa Gmail Thread ID.
